# VOID OS

a lightweight browser fake-os built for the cube/void universe. no build step. no frameworks. school chromebook approved.

## apps

- **cube#** — terminal with void/cube lore commands and a tiny fake filesystem
- **obj** — webgl cube that watches you back (drag to rotate)
- **reactor** — jbo's nuclear-ish facility simulator
- **void records** — in-browser audio visualizer (local files only)
- **lorebook** — cube/void lore bible + random transmissions
- **luxvidia panel** — shitpost gpu control panel (mango / PSU of angels / sidewaysloading)
- **file void** — fake filesystem browser

## vibe

VOID OS is a self-contained vanilla-js fake desktop. it has a boot sequence, a void/cube wallpaper, scanlines, draggable windows, a start menu, a taskbar, and `obj` as a desktop pet.

the tone is existential horror mixed with sarcasm, lowercase-friendly, and gen-z/chill where it counts. the void is watching. the geometry remembers.

## run locally

just open `index.html` in a browser. no server needed.

or spin up a tiny local server:

```bash
python -m http.server 8000
```
